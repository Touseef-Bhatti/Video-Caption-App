Measurement boundaries and interpretation

Server phase times use a monotonic clock inside the worker. Frame capture measures Chromium painting and transparent PNG creation. Pipe write includes time blocked while FFmpeg consumes PNG frames. Encoder drain measures the work remaining after the last overlay frame is sent. Output probe validates duration, dimensions, and audio. Browser stage times come from one-second polling and can differ by up to one polling interval. FFmpeg’s final speed includes the composite encode while frames stream in, so encoder work overlaps capture and pipe time. Worker/container CPU, GPU, disk I/O, and memory are not sampled by this page; use Docker or host monitoring to correlate those resources.
