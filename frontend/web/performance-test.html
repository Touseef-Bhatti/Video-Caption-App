Measurement boundaries and interpretation

Server phase times use a monotonic clock inside the worker. Parallel overlay generation reports wall time. Per-worker capture, pipe, and drain timings are aggregate work and can sum across workers. Chunks preserve global frame timestamps and merge in chunk-index order. Output probe checks duration, dimensions, frame rate, and audio. Browser job timings come from one-second polling. The final FFmpeg speed measures the composite encode. Worker CPU, GPU, disk I/O, and memory require Docker or host monitoring.
